### CHEM-000513: Hydrophobic attraction for heterogeneous molecular surfaces
- **Subfield:** Liquid-state and interfacial physical chemistry
- **Open:** Predict water-mediated association free energies for chemically patterned, curved and flexible surfaces from measurable properties. Establish when critical-drying descriptions remain quantitative.
- **Status:** A universal molecular description has remained elusive for decades. Wilding and Turci’s 2025 theory explains temperature-dependent attraction for model spherical solutes; heterogeneous real surfaces remain open.
